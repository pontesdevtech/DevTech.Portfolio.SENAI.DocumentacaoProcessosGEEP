Introdução ao Projeto de Curso

PROCESSO PROC.RE001
DOCUMENTAÇÃO DOC.001A
VERSÃO v1.0 (17/09/2026)

O Processo de Projeto de Curso é o conjunto de etapas realizadas para a criação de novos cursos e suas respectivas matrizes curriculares no SGE. O processo permite que as Unidades Operacionais criem a estrutura do curso e, posteriormente, encaminhem o projeto para apreciação da Gerência Executiva de Educação Profissional (GEEP). A partir dessa submissão, o projeto passa por uma análise da Coordenação de Educação Profissional, que poderá aprovar o projeto, solicitar ajustes ou indeferir a proposta.

1. Visão geral do processo

O Processo de Projeto de Curso é composto por duas etapas principais:

  1. Criação do curso/matriz, onde são cadastradas as informações e estruturas necessárias para o curso.
  2. Tramitação do projeto de curso, etapa em que o curso criado é encaminhado para análise da GEEP por meio de um atendimento no SGE.

A conclusão do processo ocorre somente após a análise da GEEP. Dependendo do resultado, o projeto poderá ser indeferido, retornar para ajustes ou ser aprovado.

2. Estrutura do curso no SGE

Para compreender o Processo de Projeto de Curso, é importante conhecer a forma como a estrutura curricular é organizada dentro do SGE. A estrutura segue uma relação hierárquica entre seus principais elementos, conforme apresentado na imagem abaixo.

2.1 Curso

O Curso representa a formação que será disponibilizada pela Unidade Operacional. É o nível inicial da estrutura utilizada para organizar as informações acadêmicas e curriculares.

2.2 Habilitação

A Habilitação está associada ao curso e representa a habilitação profissional correspondente à formação oferecida.

2.3 Matriz Curricular

A Matriz Curricular define a organização curricular do curso, estabelecendo os períodos, disciplinas e respectivas características. Durante o Processo de Projeto de Curso, a matriz passa por diferentes situações até que o projeto seja analisado e aprovado.

2.4 Período

O Período representa os módulos ou etapas que compõem a matriz curricular. Nele são organizadas as disciplinas que deverão ser cursadas naquela etapa da formação.

2.5 Disciplina

A Disciplina representa um dos componentes curriculares do curso e está vinculada a um período da matriz curricular.

2.6 Complementos da Disciplina

Os Complementos da Disciplina armazenam informações complementares relacionadas ao componente curricular, incluindo o conteúdo programático, os objetivos, a carga horária e outras características necessárias para a definição da disciplina.

3. Criação do projeto de curso

O processo tem início na Unidade Operacional, responsável por realizar a criação e configuração do curso no módulo educacional do SGE. Nessa etapa são cadastradas as informações do curso e construída sua estrutura curricular, incluindo habilitação, matriz curricular, períodos, disciplinas e complementos. Após a criação, o curso ainda não estará autorizado para utilização, sendo necessário concluir a tramitação do projeto e obter a aprovação da GEEP.

Importante

A criação do curso no sistema não significa que ele já esteja autorizado para oferta. A autorização ocorre somente após a conclusão do processo de análise e aprovação.

4. Tramitação do projeto de curso

Depois que a estrutura do curso é criada, inicia-se a etapa de tramitação do projeto de curso. Nessa etapa, o curso criado é anexado a um atendimento dentro do SGE. Esse atendimento é utilizado para encaminhar o projeto para apreciação da Gerência Executiva de Educação Profissional.

A Unidade Operacional realiza o encaminhamento do atendimento, disponibilizando o projeto para análise da Coordenação de Educação Profissional.

5. Resultados da análise

Após receber o projeto, a GEEP realiza a análise da proposta. O resultado dessa análise poderá ser um dos três cenários:

Indeferido

O projeto não é aprovado e o curso é inativado no sistema.

Com Ressalva

O projeto retorna para a Unidade Operacional para que os ajustes solicitados sejam realizados.

Aprovado

O projeto é aprovado e a matriz curricular passa a estar ativa para utilização.

5.1 Indeferido

Quando a análise resulta em indeferimento, a GEEP realiza o indeferimento do projeto de curso. Nessa situação, o curso é inativado no sistema e não poderá ser utilizado para a oferta de turmas.

O indeferimento significa que o projeto apresentado não foi aprovado pela GEEP.

5.2 Com Ressalva

Quando são identificadas pendências ou necessidades de alteração, o atendimento recebe o status Com Ressalva. Nesse caso, o projeto não é definitivamente rejeitado, mas retorna para a Unidade Operacional para que sejam realizados os ajustes solicitados pela GEEP.

Os ajustes podem envolver informações do curso, da matriz curricular ou do próprio atendimento. Após realizar as alterações necessárias, a Unidade Operacional deverá submeter novamente o atendimento para análise.

O processo de análise poderá ser repetido até que as pendências sejam solucionadas e o projeto possa receber uma decisão definitiva.

5.3 Aprovado

Quando o projeto atende aos requisitos da análise, a GEEP realiza a aprovação e o atendimento retorna com o status Projeto de Curso Aprovado. A partir da aprovação, são realizadas as configurações necessárias para autorizar a utilização do curso pela Unidade Operacional.

Entre essas ações está a alteração do status da matriz curricular para Ativa, além das configurações relacionadas à aplicação da matriz e às demais autorizações necessárias para a utilização do curso.

Após a conclusão dessas configurações, o atendimento retorna com o status de Projeto de Curso Aprovado e a Unidade Operacional pode providenciar a oferta de turmas para o curso.

6. Visão geral do fluxo

De forma resumida, o Processo de Projeto de Curso segue o fluxo abaixo:

1. Criação do curso
A Unidade Operacional cria e configura o curso no SGE.
2. Criação da estrutura curricular
São configuradas habilitação, matriz, períodos, disciplinas e complementos.
3. Anexação ao atendimento
O curso é associado a um atendimento para iniciar a tramitação do projeto.
4. Submissão para análise
A Unidade Operacional encaminha o atendimento para a GEEP.
5. Análise da GEEP
A Coordenação de Educação Profissional analisa o projeto.
6. Resultado
O projeto pode ser indeferido, retornar com ressalva ou ser aprovado.

7. Resumo do processo

O Processo de Projeto de Curso organiza o caminho necessário para que um novo curso seja criado, analisado e autorizado no SGE. A Unidade Operacional é responsável pela criação e configuração inicial do curso e pela tramitação do projeto por meio do atendimento, enquanto a GEEP, por meio da Coordenação de Educação Profissional, realiza a análise do projeto e define o resultado da tramitação.

  • Indeferido: o projeto não é aprovado e o curso é inativado.
  • Com Ressalva: o projeto retorna para ajustes e deve ser submetido novamente para análise.
  • Aprovado: a matriz curricular é ativada, as autorizações necessárias são configuradas e o curso pode ser utilizado para a oferta de turmas.

Dessa forma, a aprovação do projeto representa a conclusão da tramitação e a autorização para que a Unidade Operacional prossiga com a organização da oferta do curso.
