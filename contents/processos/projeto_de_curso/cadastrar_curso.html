Criar Curso no SGE

PROCESSO PROC.RE001
DOCUMENTAÇÃO DOC.003A
VERSÃO v1.0 (23/09/2026)

O cadastro de um novo curso no Sistema de Gestão Escolar (SGE) deve ser realizado a partir da identificação da modalidade, definição do código sequencial e preenchimento das informações necessárias para caracterização do curso. Após o cadastro do curso, deve ser criada sua respectiva habilitação, que permitirá posteriormente o cadastro das matrizes curriculares.

1. Identificar a modalidade e o próximo código

O primeiro passo para cadastrar um curso é identificar a modalidade à qual ele pertence e verificar a sequência de códigos já utilizada no SGE. Para isso, na tela de cadastro de cursos, utilize o filtro selecionando a modalidade correspondente ao curso que será criado. Após aplicar o filtro, o sistema apresentará os cursos pertencentes à modalidade selecionada. Em seguida, ordene os registros pela coluna Código para identificar o último código sequencial válido cadastrado e, a partir dele, definir o próximo código que deverá ser utilizado para o novo curso.

Regra para definição do código

O código do novo curso deve seguir a sequência dos códigos já cadastrados para a modalidade correspondente. Utilize como referência o último código sequencial válido encontrado na listagem.

2. Cadastrar curso

Após identificar o próximo código disponível, clique no botão Incluir para abrir a tela de cadastro. O SGE apresentará a tela destinada ao cadastro das informações do novo curso. O preenchimento envolve os dados de identificação, a configuração da máscara de turma e os campos complementares necessários para caracterizar a formação. Antes de salvar, todas as informações devem ser revisadas para garantir que estejam de acordo com os dados definidos para o curso.

2.1. Preencher a identificação

Na aba Identificação, informe o código correspondente ao próximo registro sequencial identificado anteriormente e preencha o nome completo do curso, sem utilizar abreviações. No campo Nível/Categoria, informe modalidade do curso (aperfeiçoamento, qualificação, habilitação técnica, etc.) e, no campo Modalidade, selecione o tipo de mediação utilizado para a oferta, que pode ser Presencial ou À distância. Na sequência, selecione uma das Áreas vigentes aceitas para o cadastro dos cursos, observando sua compatibilidade com o Eixo Tecnológico correspondente.

Atenção

A modalidade (tipo de mediação) Semipresencial disponível no cadastro de cursos não deve ser utilizada. Essa opção foi criada para atender necessidades relacionadas ao ensino superior. Nesse sentido, os cursos semipresenciais devem ser classificados como À Distância nesse cadastro.

2.2. Configurar a máscara de turma

Na aba Máscara de Turma, no campo Tipo de sequencial da máscara da turma, selecione a opção Período letivo e curso. Essa configuração fará com que o contador das turmas seja reiniciada a cada período letivo, mantendo o sequencial em uma faixa menor e reduzindo o risco de extrapolar o limite de três dígitos numéricos disponível para o sequencial. No campo Formato sequencial da máscara de turma, selecione a opção Numérico e, em seguida, informe a máscara da turma conforme o padrão definido para o processo.

2.3. Preencher os campos complementares

Nos campos complementares do curso, preencha a Descrição do Curso com uma breve apresentação do que o aluno irá aprender e desenvolver durante a formação. Quando aplicável, informe a CBO da Solução Integradora e, em seguida, preencha a Competência Geral, também denominada Perfil Profissional de Conclusão. Por fim, informe o Objetivo Geral e os Objetivos Específicos, garantindo que essas informações estejam de acordo com a proposta e as características da formação.

2.4. Salvar o curso

Após concluir o preenchimento das informações necessárias, revise os dados cadastrados e clique no botão Salvar o curso. Com o curso salvo, será necessário criar sua respectiva Habilitação, que é o registro no qual serão armazenadas as matrizes curriculares que forem criadas posteriormente para esse curso.

3. Cadastrar habilitação

Após salvar o curso, será necessário criar sua respectiva habilitação. A habilitação é o registro associado ao curso no qual serão armazenadas as matrizes curriculares criadas para sua formação. O cadastro deve utilizar as informações correspondentes ao curso criado anteriormente, mantendo a consistência entre os dois registros.

3.1. Definir o tipo da habilitação

No campo Tipo, informe a classificação correspondente ao curso, selecionando uma das opções consideradas neste procedimento: Formação Inicial (FIC), Formação Continuada (FIC) ou Curso Técnico. As demais opções disponíveis no campo devem ser desconsideradas.

3.2. Informar o código e o nome da habilitação

No campo Código da Habilitação, informe exatamente o mesmo código utilizado no cadastro do curso. Para evitar divergências entre os registros, recomenda-se copiar o conteúdo do campo Código do Curso e colá-lo no campo Código da Habilitação. O mesmo procedimento deve ser realizado para o nome: copie o conteúdo do campo Nome do Curso e cole-o no campo Nome da Habilitação. Dessa forma, tanto o código quanto o nome da habilitação permanecerão exatamente iguais aos dados registrados no curso.

Regra para código e nome

O código da habilitação deve ser exatamente igual ao código do curso, assim como o nome da habilitação deve ser exatamente igual ao nome do curso.

3.3. Desconsiderar os demais campos

Os demais campos disponíveis na tela de cadastro da habilitação devem ser desconsiderados neste procedimento. O preenchimento deve se limitar às informações necessárias para caracterizar a habilitação e manter sua correspondência com o curso cadastrado anteriormente.

4. Próxima etapa

Com o curso e sua respectiva habilitação cadastrados, a escola estará apta a criar a Matriz Curricular. A matriz deverá ser elaborada de acordo com as orientações estabelecidas para o projeto de curso e, após sua criação, deverá ser submetida para aprovação, dando continuidade ao fluxo do processo de Projeto de Curso.

5. Resumo do processo

O cadastro inicia-se pela identificação da modalidade e pela definição do próximo código sequencial, obtido a partir da consulta aos cursos já cadastrados para a modalidade correspondente. Em seguida, são preenchidas as informações de identificação do curso, configurada a máscara de turma e informados os campos complementares necessários para sua caracterização. Após a revisão das informações, o curso deve ser salvo no SGE.

Com o curso cadastrado, deve ser criada a respectiva habilitação, utilizando exatamente o mesmo código e nome do curso. Concluídas essas etapas, a escola poderá prosseguir para a criação da matriz curricular, que posteriormente deverá ser submetida para aprovação, dando continuidade ao processo de Projeto de Curso.
